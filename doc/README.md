## 為什麼只有一份

v2 的設計過程留下過主規格、設計筆記、施工計畫與決策紀錄，
但那些是**設計歷史**：內容已被現行規格取代，裡面還留著舊資料庫名、
舊表格名與其他專案的名稱。把它們放進一個要散布的套件裡，
讀者會分不清哪一份才是權威——所以**它們不隨包提供**。

現行規格因此是自足的：它需要的每一條規則都寫在裡面，
它提到的每一支程式碼都在 `fbf_engine/` 底下，
外部只引用有連結的公開來源。

## 找不到別的文件時

本包不含其他專案的程式碼、資料或文件。要查設計歷史或舊版規格，
請回到該專案自己的保存庫，不要在這個套件裡找。
